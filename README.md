## Tools

### [Tabular Model Cleaner 2.0](https://github.com/NuricBI/TabularModelCleaner2.0)

A **free tool for Power BI and Microsoft Fabric** that finds the measures, columns and tables
your semantic model no longer needs — and tells you which ones are safe to remove. It maps
every dependency first, including measure-to-measure chains and fields used only in filters,
so nothing used indirectly is ever reported as unused.

📖 [Full instructions and screenshots →](https://nudatabi.com/blog/tabular-model-cleaner-2-0-for-microsoft-power-bi-and-fabric/)

> The original **v1** (Data Model Cleaner for Power BI and SSAS, 2022) is superseded by 2.0.
> Its documentation and download remain in this repository's git history.
